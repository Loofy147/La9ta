# La9ta — لقطة DZ

المستودع الرسمي لمصدر العمل الخاص بمتجر «لقطة DZ». المشروع منصة لاكتشاف عروض موجودة في السوق الجزائري وتجميع **طلبات توفير غير ملزمة**؛ لا يمثل الطلب حجزًا أو شراءً نهائيًا. يجب إعادة التحقق من السعر والتوفر قبل تأكيد العرض مع العميل.

## حالة المستودع

هذا المستودع بدأ فارغًا. أول نسخة ستثبت مصدر الحقيقة وتعيد تنظيم التطبيق والاختبارات والتوثيق تحت إصدار قابل للمراجعة. لم تُنسخ ملفات طويلة من مخرجات Vercel المبتورة على أنها مصدر موثوق. النشر الحالي على Vercel يظل مستقلًا إلى أن ينجح بناء نسخة مرتبطة بهذا المستودع واختبارها في Preview.

## خريطة المستودع

- src/ — تطبيق الويب وواجهات Vercel Functions، ويُختار لاحقًا كمجلد Root Directory في مشروع Vercel المرتبط بالمستودع.
- tests/ — اختبارات مجال الطلبات وقواعد الحالات دون اتصال بمزودي الخدمات.
- docs/ — المعمارية، سجل الأدلة، سجل الإضافات، الأثر الرجعي، وإجراءات النشر والرجوع.
- .github/workflows/ — تحقق آلي من الشيفرة والاختبارات.

## مبادئ العمل

1. دليل المصدر/المستودع مقدم على الوصف الموجود في المحادثة.
2. حالة النشر READY لا تثبت أن النطاق العام يخدم هذا النشر.
3. نتائج البحث الخارجية عروض مرصودة لا مخزون مضمون.
4. السعر المرصود ليس فاتورة نهائية؛ لا دفع ولا شحن مؤكدين في خط الأساس.
5. لا تُحتسب الميزة مكتملة قبل اختبار واجهتها وAPI وتوافقها مع السجلات السابقة.
6. لا تخزّن مفاتيح أو رموز الإدارة في Git. تُدار عبر Vercel Environment Variables.
7. لا تتغير ملفات النشر الإنتاجية قبل نجاح اختبارات Preview وتوثيق طريقة الرجوع.
