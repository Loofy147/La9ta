# لقطة DZ — La9ta

المستودع هو مصدر العمل المنظم لمتجر «لقطة DZ». يكتشف عروضًا منشورة في السوق الجزائري ويجمع **طلبات توفير غير ملزمة**. إرسال الطلب لا يعني حجز المنتج أو إتمام الشراء؛ يجب التحقق من المصدر والسعر والتوفر قبل أي تأكيد نهائي.

## الحالة الحالية

- **الشفرة المصدرية:** موجودة في هذا المستودع، والتطبيق تحت `src/`.
- **التحقق الآلي:** نجحت مهمة GitHub Actions رقم **37**؛ اجتاز فحص الصياغة واختبارات المجال والخصوصية والتحقق من ملفات JSON.
- **الاختبارات:** **27 ناجحًا، 0 فشل** في تشغيل محلي معزول باستخدام Node.js 22 وعلى فرع `verification/acceptance-baseline-20261011`.
- **معاينة Vercel:** تعمل على مشروع مستقل عن المتجر القديم. فحص الصحة والبحث نجحا؛ واجهة الإدارة تُحمّل، والـAPI يرفض الطلب غير المصادق عليه بـ401.
- **غير مكتمل بعد:** اختبار إنشاء طلب محفوظ وقراءته وتحديثه من البداية إلى النهاية، واختبار تفاعلي جديد بعد إصلاح دمج الإعلان المكرر، وتدقيق كامل للدفع والشحن.
- **الإنتاج القديم:** `https://dz-pick-store.vercel.app/` لم يُنقل ولم يُغيّر alias الخاص به. لم تُنقل سجلات العملاء القديمة.

## خريطة المستودع

- `src/index.html`, `src/styles.css`, `src/app.js`: الواجهة الرئيسية وسلة طلب التوفير.
- `src/catalog.json`: ثمانية منتجات مرجعية، بأسعار تحتاج إعادة تحقق.
- `src/discover.html`, `src/discover.js`, `src/api/search.js`, `src/lib/search-domain.js`: البحث الخارجي وتصفية النتائج وروابط المصدر.
- `src/api/order.js`, `src/lib/order-domain.js`: التحقق من الطلبات وتطبيع عناصرها من جهة الخادم.
- `src/api/health.js`: فحص توافر مخزن Blob المرتبط بمشروع المعاينة.
- `src/api/admin-orders.js`, `src/api/admin-update.js`, `src/admin.html`, `src/admin.js`: القراءة الداخلية وتحديث الحالات.
- `src/source-utils.js`: الهوية المرجعية للرابط لتجنب تكرار الإعلان بين الكتالوج والبحث.
- `src/sw.js`, `src/manifest.webmanifest`, `src/icon.svg`: موارد PWA؛ التثبيت والتحديث على أجهزة فعلية ما زالا بحاجة إلى اختبار.
- `tests/`: اختبارات المجال والبحث وهوية الإعلانات وعقود الأمان والخصوصية.
- `docs/`: المعمارية والأدلة ومصفوفة الأثر الرجعي وسجل التغييرات وإجراءات النشر.

## التشغيل والتحقق

من جذر المستودع مع Node.js 22 أو أحدث:

```bash
npm run check
npm test
```

تستخدم وظائف Vercel الاعتماد `@vercel/blob` المحدد في `src/package.json`. المقصود إعداد Vercel Root Directory على `src`، وإضافة `BLOB_READ_WRITE_TOKEN` و`ADMIN_TOKEN` كمتغيرات بيئة في Vercel. لا تحفظ أسرارًا حقيقية في Git.

## قواعد لا يجوز تجاوزها

1. حالة نشر `READY` لا تثبت أنه النطاق الإنتاجي الصحيح.
2. السعر الظاهر سعر مصدر مرصود، وليس فاتورة نهائية.
3. نتيجة البحث ليست مخزونًا مؤكدًا؛ يجب أن تحتفظ باسم المصدر ورابط الإعلان ووقت الرصد في أي تطوير لاحق.
4. لا نعرض رابط API خامًا كرابط إعلان موجه إلى العميل.
5. بيانات العميل والطلبات لا تدخل في التخزين المؤقت العام.
6. لا تُعتبر الميزة مكتملة بوجود ملف أو بنجاح البناء وحده؛ نحتاج دليل تشغيل واختبارات متوافقة وخطة رجوع.
7. لا يُغيّر النطاق القديم ولا تُنقل طلباته قبل اجتياز اختبارات الطلب والإدارة في بيئة معزولة وتوثيق قرار النقل.
