# لقطة DZ — La9ta

المستودع هو مصدر العمل المنظم لمتجر «لقطة DZ». يكتشف عروضًا منشورة في السوق الجزائري ويجمع **طلبات توفير غير ملزمة**. إرسال الطلب لا يعني حجز المنتج أو إتمام الشراء؛ يجب التحقق من المصدر والسعر والتوفر قبل أي تأكيد نهائي.

## الحالة الحالية

- **الشفرة المصدرية:** التطبيق والاختبارات والتوثيق موجودة تحت إدارة Git في هذا المستودع.
- **CI:** نجح GitHub Actions run #38 على commit `a9dfe0385d72d45b94facc4b35c0673090033ec3`: https://github.com/Loofy147/La9ta/actions/runs/38152744176
- **الاختبارات:** 27 ناجحًا و0 فشل في تشغيل Node.js 22 مستقل، كما نجحت خطوات الصياغة والاختبارات وملفات JSON في CI.
- **المعاينة:** مشروع Vercel مستقل عن المتجر القديم؛ فحص الصحة والبحث ناجحان، ورفض API الإدارة للزائر دون رمز ثبت بـ401.
- **الطلب:** استقبلت المعاينة طلب اختبار اصطناعيًا بـ201. الطلب ذو ID مجهول، والكمية الصفرية، وحقل مكافحة الروبوتات المعبأ رُفضت جميعها بـ422.
- **اختبار اصطناعي متبقٍ:** سجل `DZ-C3A8D87B` موجود في مخزن معاينة مستقل فقط، باسم اختباري وهاتف صفري، ولا يمثل عميلًا حقيقيًا. لم يُثبت بعد استرجاعه عبر API الإدارة أو تحديثه لأن التحقق الإيجابي باستخدام رمز الإدارة لم يكتمل.
- **الإنتاج القديم:** `https://dz-pick-store.vercel.app/` لم يُنقل ولم يُغيّر alias الخاص به. لم تُنقل سجلات العملاء القديمة.

## خريطة المستودع

- `src/index.html`, `src/styles.css`, `src/app.js`: الواجهة الرئيسية وسلة طلب التوفير.
- `src/catalog.json`: ثمانية منتجات مرجعية بأسعار تحتاج إعادة تحقق.
- `src/discover.html`, `src/discover.js`, `src/api/search.js`, `src/lib/search-domain.js`: البحث الخارجي وتصفية النتائج وروابط المصدر.
- `src/api/order.js`, `src/lib/order-domain.js`: التحقق من الطلبات وتطبيع عناصرها من جهة الخادم.
- `src/api/health.js`: فحص توافر مخزن Blob المرتبط بمشروع المعاينة.
- `src/api/admin-orders.js`, `src/api/admin-update.js`, `src/admin.html`, `src/admin.js`: القراءة الداخلية وتحديث الحالات.
- `src/source-utils.js`: توحيد هوية الإعلان لتجنب تكراره بين الكتالوج والبحث.
- `src/sw.js`, `src/manifest.webmanifest`, `src/icon.svg`: موارد PWA؛ اختبار التثبيت والتحديث على جهاز فعلي ما زال مفتوحًا.
- `tests/`: اختبارات المجال والبحث وهوية الإعلانات وعقود الأمان والخصوصية.
- `docs/`: المعمارية وسجل الأدلة ومصفوفة الأثر الرجعي وسجل التغييرات وإجراءات النشر.

## التشغيل والتحقق

مع Node.js 22 أو أحدث من جذر المستودع:

```bash
npm run check
npm test
```

يُضبط Vercel Root Directory على `src`. تدار `BLOB_READ_WRITE_TOKEN` و`ADMIN_TOKEN` عبر متغيرات بيئة Vercel فقط. لا تحفظ أسرارًا حقيقية في Git أو سجلات الاختبارات.

## قواعد لا يجوز تجاوزها

1. حالة نشر `READY` لا تثبت أنه النطاق الإنتاجي الصحيح.
2. السعر الظاهر سعر مصدر مرصود وليس فاتورة نهائية.
3. نتيجة البحث ليست مخزونًا مؤكدًا.
4. لا يُعرض رابط API خام كرابط إعلان موجه للعميل.
5. لا تدخل بيانات الطلبات في التخزين المؤقت العام.
6. لا تكتمل الميزة لمجرد وجود ملف أو نجاح البناء؛ يلزم اختبار ودليل قابل لإعادة الفحص.
7. لا يُغيّر النطاق القديم ولا تُنقل طلباته قبل اجتياز دورة الطلب والإدارة في بيئة معزولة ووجود خطة رجوع.
